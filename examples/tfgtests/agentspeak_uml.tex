\maketitle

\noindent Scope: the interpreter classes in \texttt{agentspeak/\_\_init\_\_.py}
and \texttt{agentspeak/runtime.py} that the standard-library actions actually
touch, plus every internal action implemented in this project (marked
\texttt{\#Enric} in \texttt{stdlib.py}), grouped the same way the project's
own function table groups them. Pre-existing baseline actions (\ia{.print},
\ia{.findall}, \ia{.wait}, \ldots{}) are omitted --- this is a map of what was
\emph{built}, not the whole standard library.

\bigskip
\noindent\textbf{Colour key.} Grey boxes are the interpreter's own runtime
classes (unmodified); the external \texttt{spade\_bdi} layer is warm brown;
the four implemented-action groups are blue (BDI/intentions), ochre (plan
library), plum (agent life-cycle) and teal (term/environment/scheduling). The
diagram shows structural relationships only (composition/aggregation between
runtime classes); which action group reads or mutates which piece of state is
listed separately in Table~\ref{tab:touches}, since as free-standing
signatures they have no natural tree structure to draw as edges without
crossing.
